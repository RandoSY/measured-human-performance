# Movement Data Logger — micro:bit lineage

**Source repository:** https://github.com/RandoSY/movement-data-logger

**Source snapshot:** `24e6d51301cca6866d4ad5e042226618f739b787` (3 Sep 2024)

**Disposition:** preserved estate-owned lineage under Measured Human Performance.

This original MakeCode micro:bit project records X/Y/Z acceleration every 100 ms while logging is enabled. Button A starts logging, Button B stops it, and A+B clears the log and restores the X/Y/Z column headings.

It is useful historical infrastructure for the later FFT/SQM+ movement-measurement work because it captures the simplest form of the measurement pipeline: an inexpensive wearable board, raw inertial observations, explicit start/stop control, and recoverable data.

The original repository remains intact. The human-readable TypeScript source and MakeCode project metadata are copied here so the lineage survives inside the canonical estate. The generated Blockly editor file and GitHub Pages scaffolding remain available in the source repository if exact editor reconstruction is required.

No claim is made that this historical project is a current SQM+ implementation.
